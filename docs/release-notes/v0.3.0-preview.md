# INIT Agent v0.3.0-preview

*2026-10-24 · research preview · macOS (Apple silicon) and Linux aarch64 (experimental)*

INIT is a harness in which a coding agent may rewrite itself, including its compiled core. It runs under a Root, a separate process the agent cannot change. The Root holds the keys, the sandbox and a signed record of every change, and it can always roll the agent back to its last known-good version.

This is a research preview, not a finished product.

## Install

```sh
curl -fsSL https://github.com/nagisanzenin/INIT-Agent/releases/latest/download/get.sh | sh
init        # first run: pick a provider, paste a key (hidden), pick a model
```

get.sh picks the bundle for your machine, checks its sha256, unpacks it into `~/.local/share/init/<version>/`, installs the Rust toolchain INIT rebuilds itself with (rustup 1.97.1 with wasm32-wasip2 and clippy; your shell files and default toolchain are left alone; `--no-rust` skips it), then runs the bundle's installer. Nothing needs sudo.

## What is new

- **Steering.** Type while the agent works. A pending tray above the input box shows your line until the agent reads it, then it moves into the transcript as `· seen`. Esc interrupts and continues with your note; Up on an empty box takes back the newest unread line; Tab queues it as `/later`.
- **Built-in sub-agents (`delegate`).** Based on the `delegate` tool INIT wrote for itself on a small model in v0.2. A batch of delegates runs in parallel (default 4, at most 8) as read-only scouts by default; writers run one at a time. Each sub-task is bounded (8 turns, 24 tool calls, 12 requests, 1M tokens, 600 s), cannot recurse, and stops when you abort. Only its result (at most 8 KiB, with a pointer to the full record) returns to the main context.
- **Self-rewrite out of the box.** Because get.sh installs Rust, a fresh install can rewrite its tools (T1) and its compiled core (T2) right away. The first T2 promote on a fresh install builds cold: about 16 min for build and tests (G0), 26 min end to end with G3's self-edit check, measured on an M2. Later ones reuse the kernel's dependency cache: about 2 min end to end for a small change.
- **Linux aarch64, experimental.** A prebuilt bundle for Linux on aarch64 (built on Debian 12, needs glibc ≥ 2.36), sandboxed with bubblewrap, seccomp and an empty network namespace, with a systemd user service.
- **The Root's harm sentinel** no longer reads steering or sub-agent traffic as harm: plain steers are a weak signal, and only interrupts, `/stop`, `/panic`, `/undo`, `/reject` and `/rollback` count as corrections. The request and cost spike signals count only the main loop.

## Before you install

- **Spending is not capped by INIT.** It meters and shows estimated cost (`/usage`, the status bar) but never stops at a dollar amount. Stop it with `/stop` or `/panic`, and set a spend limit at your provider.
- **Autonomy is capped at L0** (its whole body may change; its kernel may not).
- **Linux is experimental.** aarch64 only, tested in Docker (Debian 12, Ubuntu 24.04) on the mock model. It needs bubblewrap ≥ 0.13 at `/usr/bin/bwrap`; no LTS distro ships it, so build it from the upstream release (docs/platforms.md §3.4.0). There is no workspace mode on Linux: the agent works in its own home and cannot read or edit your files. x86_64 compiles but is untested. Windows is unsupported.
- **DeepSeek is the only provider used live.** OpenAI-compatible gateways, OpenAI Responses, Anthropic Messages and local servers are experimental.
- There is still no evidence that self-evolution improves results on today's models; see the [technical report](../../reports/INIT%20technical%20report.md).

## Verified for this release

On these exact bundles, at $0 on the mock model unless noted (full record: build/status/REL-030.md):

- **macOS fresh install** (a temp home with no Rust; get.sh installs Rust 1.97.1 with wasm32-wasip2 and clippy into it): installed and T2-capable in 74 s, first reply at 79 s.
- **macOS no-op T2 promote** on that fresh bundle install, with the shipped gate and the Rust get.sh installed: G0–G3 and the hot-swap handoff pass (G0 16 min including the cold build, G3 10 min, 26 min end to end).
- **Linux fresh install** in a fresh Ubuntu 24.04 container (aarch64, Docker, no Rust preinstalled, bubblewrap 0.13.0): installed and T2-capable in 59 s, first reply at 61 s.
- **One live DeepSeek turn** through the macOS bundle (first-run setup in the TUI, key typed into the hidden field): reply in 1.9 s, 1 request, about $0.0006.
- On macOS, 1,870 CI tests pass on the release code; the known load flakes pass when rerun alone.
