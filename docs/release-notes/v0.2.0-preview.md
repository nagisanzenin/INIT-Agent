# INIT Agent v0.2.0-preview

*2026-10-23 · research preview · macOS only*

INIT is a harness in which a coding agent may rewrite itself, including its compiled core. It runs under a Root, a separate process the agent cannot change. The Root holds the keys, the sandbox and a signed record of every change, and it can always roll the agent back to its last known-good version.

This is a research preview, not a finished product.

## What we found

In a pre-registered trial on a cheap real model (deepseek-flash, $2.67), the whole loop ran end to end:
1. the evolution engine found a failure pattern in the agent's own runs, and the agent wrote a change for it;
2. the change passed the build and boot gates and was hot-swapped into the running session;
3. a sealed gate on tasks the agent never sees did not establish that the change was no worse than the current version within a 120‰ margin (d = −50‰, inside the measured noise of 57‰);
4. the Root rolled the change back automatically.

This is one data point. It shows that the loop and the rollback work on a real model, and that a cheap visible estimate (+120‰) and a sealed measurement can disagree. It does **not** show that the change was harmful, and it does **not** show that self-evolution helps. A later test on the same model found no task where a missing mechanism, rather than the model, was the limit, so the evolution phases never ran. See the [technical report](../../reports/INIT%20technical%20report.md).

## What is in this release

- **Reward-free self-extension (ADR-011).** `extend.mode = "gated"` (default: every change passes gates G0–G4) or `"free"` (mechanical checks, then a Root harm sentinel that rolls back changes that cause crashes, refusals, owner stops, or cost and error spikes). Snapshots, attribution per capability, selection by use, owner grants (`/grant`, `/deny`) and a frozen twin for comparison.
- **Memory watchdog.** The Root kills a tool call's process tree that passes the memory cap (default 4 GiB) and refuses new work below a free-disk floor.
- **Observe-only spending.** The Root logs every model request with token usage and an estimated cost and shows it in the status bar and with `/usage`. It does not stop at any dollar amount.
- **Codex-style permissions** with `/undo` snapshots of your project folder.
- **Groundwork, not yet qualified:** more provider types, a Linux sandbox, kernel self-upgrade, and a release A/B harness.

## Before you install

- **Spending is not capped by INIT.** A self-modifying agent can keep spending until you stop it with `/stop` or `/panic`. Set a spend limit at your provider; for DeepSeek, keep the prepaid balance small.
- **Autonomy is capped at L0** in this build.
- **macOS only.** Linux is unverified; Windows is unsupported.
- **DeepSeek is the only provider used live.** OpenAI-compatible gateways, OpenAI Responses, Anthropic Messages and local servers are experimental: code and offline tests only.
- The install wizard still asks for daily and total "spending ceilings"; the answers are stored but not enforced.
- No real-model request has been made on this exact code since the spending and provider changes; those changes are tested at $0 on a mock model and in macOS CI.

## Install

```sh
scripts/install.sh
~/.init-root/bin/init-root keys set deepseek
init
```
