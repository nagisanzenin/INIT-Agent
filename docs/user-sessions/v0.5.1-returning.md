**Harness artifacts.** Each is listed with what it changed.
1. **The get.sh download was swapped for the local candidate**, as the brief allowed. A zsh accept-line hook (the operator's) rewrote each line that fetched INIT's get.sh from GitHub, and printed a "[test harness]" line under it.
   - The README line became `cat <candidate get.sh> | sh -s -- --from <tarball>`.
   - The printed upgrade line became `… /bin/sh -s -- --upgrade --from <tarball> --sha256 <hex>`.
   - Effect: get.sh copied the local bundle into ROOT_HOME/cache/upgrade and checked it against `--sha256` instead of downloading it and taking latest.json's sha256. Every other line of output is the candidate's own.
   - The README line stopped before the download, at the "already installed" check, so the substitution did not affect it.
2. **No LaunchAgent: the Root ran in the foreground.** That is why the upgrade first refused ("runs without the service. Stop it in its terminal (Ctrl-C)") and why the persona restarted the Root by hand.

4. **"Last week" was a minute before the session.** So "/usage $0.005 today = all-time" is correct. The persona said so itself.
5. **The scripted model** ran `done 1` on the persona's real list.
6. **todo.py and todo.json were mode 0600** because of the harness tmux server's umask 077, not INIT's choice.
