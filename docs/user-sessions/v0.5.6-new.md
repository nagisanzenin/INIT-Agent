WHAT WORKED
- I opened a new terminal and typed `init-agent`, as the README says, and it came up. Setup was three steps (provider, key, model) and took under a minute. The key was masked as I pasted it, and the screen said "[root] key stored for deepseek (mode 0600; never shown)".

- Self-change: a gate panel showed each step with its time. It ended with "✓ kept 748f7cafcf3c · 4/4 gates · G4 not scored · 24 min 5 s · no restart".
- /usage adds up (details in the numbers section).
- I quit with Ctrl-D and came back with the exact line it printed. The whole conversation was still there.
- /undo list was clear. It skips the snapshot that is "same as the folder now". /undo emptied my folder (hello.py gone, checked with ls). It saved the old state first, and `/undo <id>` brought hello.py back (checked, and it ran).
- /panic told me what I would lose before I confirmed ("What you lose: … the self-changes kept since t3d78df0047bb no longer run"). Each jargon line came with an "in plain words" line. /resume restarted the agent and it answered again.
- The uninstaller listed exactly what it would move to the Trash and made me type `uninstall`. Afterwards `init-agent` gave "command not found" in the old window and in a new one, ~/.init and ~/.init-root were gone, and my hello.py was untouched.

- I asked for a tool that counts the lines in a file. Its description says "count the lines of a workspace file that contain a substring", which is not what I asked for.
