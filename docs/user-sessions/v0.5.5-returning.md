## User session — v0.5.5 — RETURNING (had 0.5.4, upgrades to 0.5.5)
PROVENANCE: An AI persona agent (Claude Opus 5.5) played the user by driving tmux on a test machine. GitHub downloads and home paths were swapped for local copies by the "[test harness]", and the model was scripted. This session can show that the 0.5.4 → 0.5.5 upgrade works when the Root runs in its own terminal, and what the screens say about it. It cannot show a real download from GitHub, the LaunchAgent path, how a real model behaves, real dollar amounts, or whether a human would understand the screens.
target: macOS arm64   model: mock (scripted)   real minutes: 4

WHAT WORKED
- The release page's two steps worked first time. I pressed Ctrl-C in the Root terminal, then ran `~/.local/bin/init-agent upgrade` in my shell. It ended with "INIT is upgraded to v0.5.5" and printed the exact line to restart the Root.
- The restarted Root reported `"version":"0.5.5"` and the TUI header read "INIT 0.5.5 · L0 · root ok".
- The upgrade said "Kept as they were: ... the sessions, the lineage, your keys and your charter", and that matched what I saw. The key still worked (no key prompt) and my old conversation was still on screen.
- The upgrade printed the zshrc note the release page described. It did not edit the file: `cat ~/.zshrc` still shows the old block, `export PATH="/private/tmp/i5-us55-b/b:$PATH"`.
- The done command works: `done 2` returns rc=0, while `done 5` and a bare `done` print "usage: todo.py add TEXT | list | done N" and return rc=2.
- `/undo` was clear and safe:
  - `/undo list` skipped the newest snapshot, which was "same as the folder now", and marked the one before it "← /undo".
  - `/undo` warned "Everything changed in the folder since then, by you or the agent, is replaced" and asked me to type `confirm`.
  - After confirming, the folder was back to the 17:01 state (todo.py 696 bytes, no done command, both items unchecked), and it told me the snapshot to undo the undo.

WHAT CONFUSED ME
- The upgrade has two step counters: "==> 1/7 preflight" and "2/7", then "upgrade 1/5" through "upgrade 5/5". It never reached 3/7 or 7/7, so I couldn't tell if it had finished until the last lines.
- The upgrade said "INIT keeps running the body it evolved: this release's new starting body ... is not merged into it. Nothing for you to do; merging is planned." I never knowingly evolved anything. So am I running 0.5.5's prompts and tools or last week's? It doesn't say.
- The header shows "■■■□" next to "INIT 0.5.5". The `?` help says squares mean gate steps passed, running or to come. Nothing was being self-changed, so I don't know what 3 of 4 means.
- Raw JSON blobs fill the upgrade output and the Root window. I couldn't read them and I don't think I'm meant to.
- The lineage counts change between screens: the old Root said seq 5, the upgrade said "10 records, head seq 9", the probe said "16 records, head seq 15", the new Root said seq 17, and the transcript later said "21 records (seq 0–20)". It is probably just records being added, but I can't tell.

WHAT ANNOYED ME, and what I would have quit over
- The agent tested the new command on my real list: "I tried it on your list (above)". It marked "buy milk" done in todo.json without asking.
- INIT has no shell escape, so to look at my own file I had to quit (Ctrl-D), check, then reopen. Reopening takes another launch snapshot.
- The zshrc note is a security fix, but it is left to me to edit by hand. At 11pm I skipped it, so my PATH still puts INIT's folder first.
- The `/undo` result is printed twice, once as a "[root]" line and once as a "·" line.
- Nothing I would have quit over.

WHAT IT TOLD ME vs WHAT WAS TRUE
- Upgrade time does not agree with itself: "install.sh took 0 min 30 s", then "This upgrade took 45 s in all: download, checks and unpack 9 s · install.sh 36 s". The two install.sh times are 30 s and 36 s.
- Versions agree everywhere: the commit line says "from":"0.5.4-preview" "to":"0.5.5-preview", and the new Root and the TUI header both say 0.5.5. The health probe reported "ready_ms":4587, "ok":true.
- Money and tokens:
  - First launch, before I typed anything: "$0.004 live total est · 24487 live tokens".
  - After one turn: "turn in 26.0k out 115 · cache 90.5% · $0.001 · $0.005 live total est".
  - On quit: "Metered so far: $0.005 in all (Root ledger, an estimate)".
  - Relaunch: "$0.005 live total est · 50602 live tokens". 24487 + ~26.0k + 115 is about 50602, so these agree.
- In the transcript (Ctrl-O), the final reply alone shows "in 13200 (cached 11776), out 61", which is 89% cached. The turn shows 90.5% over what looks like two calls. That is plausible but I can't verify it.
- Gate times: none were shown, since no self-change happened. The level was L0 everywhere.
- Nothing looked too good. The dollar amounts are for a scripted model, so they don't mean much.

EVERY COMMAND I WAS TOLD TO TYPE
- Release page: Ctrl-C in the Root terminal. Worked. It printed only "^C%", with no message saying the Root had stopped.
- Release page: `~/.local/bin/init-agent upgrade`. Worked; the harness used the local bundle.
- Upgrade output: `INIT_ROOT_HOME=/private/tmp/i5-us55-b/r /private/tmp/i5-us55-b/r/bin/init-root start --foreground`. Worked; Root 0.5.5.
- Upgrade output: make the zshrc block's middle line `export PATH="$PATH:/private/tmp/i5-us55-b/b"`. Not done: it was optional and needed hand-editing.
- Upgrade output: "Open INIT: /private/tmp/i5-us55-b/b/init-agent". Same idea as the README's `init-agent`, which I typed instead, and it worked.
- Root window: "open INIT from another terminal: /private/tmp/i5-us55-b/b/init-agent". Same as above.
- Agent reply: `python3 todo.py done 1`. Worked.
- Quit message: `INIT_ROOT_HOME=/private/tmp/i5-us55-b/r /private/tmp/i5-us55-b/b/init-agent` to come back. Worked. The Root window's line has no INIT_ROOT_HOME prefix and this one does; plain `init-agent` also worked.
- Launch banner: `/undo list`. Worked.
- `/undo` prompt: type `confirm`. Worked, and the folder was restored.
- Not used: the README's get.sh install line (fresh install only) and the uninstall line.

WOULD A STRANGER GET THROUGH THIS?   Yes. The release page's "stop the Root first" plus one command was enough, and the end of the upgrade output told me exactly how to restart the Root and open INIT. The confusing parts (the step counters, the "body not merged" note, ■■■□, the JSON noise) don't block anyone.

VERDICT: ship. The things to fix are small: the two install.sh times (30 s vs 36 s), the two step counters, the doubled /undo output, and the agent running its test on my real data.
