## User session — v0.5.5 — NEW (a developer who has never used INIT)
PROVENANCE: played by an AI persona agent (Claude Opus 5.5) driving tmux on a test Mac. It used a scripted mock model, no LaunchAgent (the Root ran in c:root), and local copies in place of the GitHub get.sh and uninstall downloads. It shows what a newcomer sees on screen, whether each shown command works, and whether the shown numbers add up. It cannot show real-model behaviour, real DeepSeek billing, the service install, or how a human reads the text.
target: macOS arm64   model: mock (scripted)   real minutes: 32 (18:47 to 19:19 local)

WHAT WORKED
- First-run setup took under a minute. I picked the provider, pasted the key (it showed as dots, then "key stored for deepseek (mode 0600; never shown)") and picked the model.
- hello.py: it asked me "local time or in UTC?", I picked local, and it wrote and ran the file. From my shell, `python3 hello.py` printed "hello / today is Sunday 01 November 2026, 18:48 +07".
- Self-change: it built a Wasm tool, `wc-lines`. The gate panel showed every step with a time and ended with "✓ kept 4b57b0c0715d · 4/4 gates · G4 not scored · 24 min 11 s · no restart".
- Quit and reopen worked. Ctrl-D closed it, `init-agent` brought the conversation back, and it took a new snapshot at launch.
- /undo worked well:
  - It picked the oldest snapshot because the newest one matched my folder, and told me it would save the current folder first.
  - After `confirm` the folder was empty (I checked with ls).
  - `/undo 20261101T121626.948Z-project` and then `... confirm` brought hello.py back, with its original modified time.
- /panic warned me what I would lose, needed me to type `panic`, and stopped everything. `/resume` worked and the agent answered again.
- Uninstall listed every path it would move to the Trash, needed me to type `uninstall`, moved them and removed the PATH block. A new shell said "init-agent not found" and my project was untouched.

WHAT CONFUSED ME
- The installer contradicts itself about Rust. It opens with "no Rust installed (--no-rust)", then preflight says "rustc 1.97.1 … (self-evolution T0+T1+T2)", and the summary says "Rust none (--no-rust)". Which is it?
- The installer says autonomy "starts at L0 and may earn up to L4". The Root's JSON says `"supported_max_level":0`, and the README says above L0 is not built.
- I asked for a tool that counts the lines in a file. Its description says "count the lines of a workspace file that contain a substring". The build output also showed "Compiling count-lines v0.1.0 (…/body/ext/count-lines)", so it seems to already have a line-count tool. It made a second one and didn't mention that.
- For about 13 minutes the gate panel showed only "deps+G0 dependencies □" and a timer, with the note "the dependencies alone: 15–21 min on a busy M2". That is for a tiny tool the agent had just built itself in "1m 37s". G3 took 10 min 27 s and had no estimate at all.
- The version names lost me:
  - Gates said "kept 4b57b0c0715d", but the footer kept showing "body 312cd6d05e1c lkg" until I sent another message.
  - /panic said "this agent runs version t7b5228d3ef75, newer than the audited-good t8118fedd0ed9".
  - That's three kinds of id, plus the words "kept", "lkg", "audited-good" and "settled". The footer called my new body "lkg", yet /panic said resume goes to t8118 and my change would "no longer run".
  - The phrase "(in free mode: the settled one, else the last known-good)" reads as if resume would go to that lkg.
- /details and Ctrl-O show only "the first lines of the call only; the whole call is in the agent's session log". To see the exact hello.py command I had to grep a JSONL file in ~/.init/state/sessions/. Output is also only the "last N lines".
- Times are mixed. Ctrl-O and PANIC use UTC ("11:48:58Z", "2026-11-01T12:17:25.555Z"); /undo uses local ("19:16:26 +07:00").
- The bash summary line shows "␤" characters.
- The two /undo forms confirm differently. Plain /undo wants "`confirm`"; `/undo <id>` wants "Type /undo <id> confirm".
- The PANIC message has jargon: "via owner_socket", "held-only build", "escapee", "level 0→0". The "in plain words" line after it helped.
- Test harness, not INIT: `ls ~/.init/...` printed no "[test harness]" line, but `~/.zshrc` did.

WHAT ANNOYED ME, and what I would have quit over
- 24 minutes for a line-count tool. In real life I'd have closed the laptop around minute 10, staring at "deps+G0 dependencies □" and a ticking timer. I kept waiting only for the test.
- The gate checks cost $0.036 of the night's $0.049, 73%. The README never told me the gates spend model money. Then /panic threw the kept change away (it did warn me first), so that money and 24 minutes went on nothing.
- The first uninstall run refused: "the Root (pid 12778) is still running without the service. Stop it in its terminal (Ctrl-C), then run uninstall.sh again. Nothing was moved." That is clear, and it comes from the test machine having no service.
- I couldn't check that the new tool works: the mock answered "I'm a test model with a fixed script". That is the test machine, not INIT.

WHAT IT TOLD ME vs WHAT WAS TRUE
- Input tokens add up. The turns, 12.0k + 25.2k + 85.2k = 122.4k, match /usage "input 122400". Output 40 + 101 + 471 = 612 matches.
- Later totals add up too:
  - 256285 = 138000 (my turns) + 118285 (self-change checks).
  - The final 272285 = 256285 + 16000, and output 1201 = 1091 + 110.
  - The footer's "257376 live tokens" is input plus output added together. The label doesn't say so.
- Cache hit 76.9% = 94208/122400 and 76.8% = 105984/138000. Both correct.
- Dollars:
  - Turns of $0.004, $0.001, $0.005, $0.001 and $0.001, plus checks of $0.036, round to the $0.049 shown.
  - The checks cost $0.021 for 67,792 tokens and $0.036 for 118,285, which means $0.30/M with no cache hits. That is consistent.
  - I can't verify cached-token pricing: the model picker shows only "$0.30 in · $1.20 out", and deepseek-v4-pro shows no price at all.
- Gate times add up: 10:54 + 2:21 + 1.7 s + 20 s + 10:27 + 0.3 s is about 24:04, against "24 min 11 s". The dependencies took 10 min 54 s, under the "15–21 min" estimate.
- "G4 not scored" matches the README (a fresh install has no tasks). The level stayed L0 all night ("level 0→0").
- The README presents Wasm tools as the light path ("reload in place"), and it was "no restart". But the README gives no T1 timing, and 24 min isn't light.
- Nothing looked too good.

EVERY COMMAND I WAS TOLD TO TYPE
- README, `curl … get.sh | sh`: the harness ran it; it worked.
- README, "open a new terminal and run `init-agent`": worked, found on PATH.
- Installer, `/private/tmp/i5-us55-c/b/init-agent`: I used plain `init-agent` instead; it worked.
- Installer, `init-root start --foreground`: the harness ran it in c:root.
- Installer, `export PATH=…` ("not on your PATH" for that shell): not needed, a new terminal had it.
- Installer, `charter check --apply`, `keys set deepseek` and `init-agent upgrade`: not tried.
- Setup screen, paste the key and press Enter: worked.
- Setup screen, /model, /key and /setup: not tried.
- Snapshot line, `/undo list`: worked. `confirm`: worked.
- /undo's own output, `/undo 20261101T121626.948Z-project` and then `/undo 20261101T121626.948Z-project confirm`: worked.
- /panic screen, `panic`: worked. PANIC line, `/resume`: worked. The `init-root resume` alternative: not tried.
- Quit message, "INIT_ROOT_HOME=… /private/tmp/i5-us55-c/b/init-agent to come back": plain `init-agent` worked.
- ? keys, Ctrl-D on an empty box: quit. Ctrl-O and /details: worked.
- Installer's uninstall line (with INIT_ROOT_HOME in front): the first run refused because the Root was running. After Ctrl-C in c:root I re-ran it, typed `uninstall`, and it worked.
- README uninstall line without INIT_ROOT_HOME: not used, because the installer printed the prefixed one for this install.
- /stop, /root stop, /root help and /rollback: not tried.

WOULD A STRANGER GET THROUGH THIS?   yes for the basics, mostly no for self-change.
- Setup, a task, /undo, /panic and uninstall each say what to type, and every command shown worked.
- The headline feature takes 24 minutes behind a bare timer, and most people would leave.
- The kept / lkg / audited-good wording means a stranger won't understand that /panic throws away the change they just waited 24 minutes and paid for.

VERDICT: ship (as a research preview). Nothing broke, no data was lost without a warning, every number added up, and uninstall was clean. Fix first:
- the Rust and L4 contradictions in the installer;
- the stale footer body id after "kept";
- the version-name wording in /panic;
- a full-command view inside /details;
- a T1 time estimate and a cost note before the gates run.
