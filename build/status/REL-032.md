## Decisions
- Disk guard: a watchdog pauses `rel032-build` (docker pause) below 12.8 GB free and resumes it above 14 GB; the
  macOS release uses `--lean` (release target dirs removed once staged).
- The first bless attempt failed (`couldn't get the current directory`) because INIT_SEED_G0_DIR was passed as
  `kernel/../seed/target/g0`: Seatbelt `subpath` params must be canonical. Rerun with the canonical path passed.
- The CI run is ci/local.sh's commands for what changed (seed, tui, the version string everywhere), not the full
  script: the Root (root/) is unchanged since v0.3.1 but for its version, so `root test`, `root test (test-fixtures)`,
  `promote under Seatbelt` and the sealed-pack steps were not rerun (v0.3.1's CI ran them green on the same root/ code).
  The kernel test step ran in full against the new body and root binaries, as ci/local.sh runs it.
- Pause check (new, in this lane's scratch, not committed): a patched copy of scripts/bundle-e2e.sh (test home
  `target/test-homes/ubp`, `UBE_NO_RUST=1`, the same owner-state snapshot and checks). Its mock stalls the first turn
  30 s after one event; the driver sends SIGINT to `init --raw` (our child) 2 s after `busy`, expects the display
  `paused · type to continue, or say what to do instead` and no `aborted`, idle, then sends "Please continue." and
  expects the second turn's reply, `[init:paused]` in the recorded resume request and not in the first request.
  Harness errors fixed on the way: a `last_text_contains` on the owner line (the body appends `[init:reload]` after it),
  and the record list included `mock.log.jsonl`.
- DeepSeek smoke harness (scratch): written anew from REL-030's description. Two harness errors before the passing
  run, neither with an owner line: the start folder was the test home, whose
  workspace snapshot held the first Enter (now an empty `ws/`), and a driver wait on the pty child's exit without
  draining the pty (fixed; the stuck driver, our own PID, was killed). Then "already selected" did not match
  "selected" (setup had passed; fixed).
