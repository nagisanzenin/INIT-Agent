## Deviations
1. **Size budget.** The Root is at **2,016 counted lines** (root.md §4.8 method: non-blank, non-comment, excluding `#[cfg(test)]` and `testfix.rs`). The budget is ≤ 1,500 for the whole Root, with about 365 for the WP20 modules. By module:
   - cli 321, link 346, charter 318, install 285, lineage 141, util 140, egress 138, panic 111, sys 79, sealed 58, ledger 41.

   With WP21–WP25 the projection is about 4,000–4,500. That budget cannot be met at the specified feature set. I did not contort the code to chase it. Decision needed, see below.
2. **Key path.** Keys go to `keys/providers/<id>` (and `keys/actions/<id>`), as root.md §3.2.1 and egress.md §3.2 say. The WP brief's `keys/<provider>` is not used.
3. **ROOT_HOME length.** ROOT_HOME may be at most 80 bytes in `test-fixtures` builds and 64 in release. Test homes under `root/target/test-homes/wp20/` are 66 bytes or more, and 80 still fits `sun_path` for `run/*.sock`.
4. **`start`.** `start` always runs the daemon in the calling process, because launchd and systemd run plain `start` (§4.3). `--foreground` only echoes the boot status to stderr.
5. **R-F5.** The check covers the skeleton's top-level directories, not every top-level entry of INIT_HOME. Otherwise a zone-created file there would halt the Root, which is a denial of service.
6. **C13 production minimums are mine**, because the doc gives only examples. Examples: `hb_interval_s ≥ 1`, `crash_window_s ≥ 60`, `safe_auto_clear_s ≥ 3600`, `owner_queue_max ≥ 10`, plus `hb_stale_s ≥ 3 × hb_interval_s`. Test mode lifts them to ≥ 0. Mirror and poll intervals may go down to 1 s in test mode.
7. **Charter details:**
   - `mirror.url` defaults to `""` (off) when the key is absent; the template writes the D13 URL.
   - The built-in `crates` class uses `paths = ["*"]` on both hosts. The per-host path split is WP22's.
   - A C1 type error is reported once per table, and its rule findings are dropped.
   - `sealed.margin_max` is digested and published as `margin_max_permille`, because ICJ allows integers only.
   - `sealed::validate` takes typed arguments rather than a `toml::Table`.
   - `charter.json` publishes `constitution: {"sha256": "sha256:<hex>"}`, following awareness.md's `constitution.sha256`.
8. **The fake clock is frozen between moves**, for determinism.
9. **Test-ledger spec.** The spec format is defined here: `{"start_at", "start_level", "records": [{"at", "kind", "data", "by"?, "count"?, "step_s"?}]}`, with `{i}` substitution. Ladder-up records carry `criteria: null` and `trigger{kind:"test_fixture"}`. `install` accepts a pre-seeded test chain: it skips `genesis` and appends `charter`.
10. **Not yet wired:** the panic CLI fallback only writes the latch (channel `cli_fallback`), with no SIGUSR1, self-sweep or kill. Zone start and stop and resume's rollback are stubs. The Root sits in `stopped`.
11. A rejected owner-socket peer is closed without a reply, and the CLI reports a protocol error.
