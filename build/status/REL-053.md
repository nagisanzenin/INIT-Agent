- **Tested live:** DeepSeek (earlier releases; the codec is unchanged). OpenAI gpt-6.1-sol was qualified live on

  not change (§5.6); lane M changes the meter, so this needs either a re-qualify on the candidate (owner's go, cap) or
  the label "experimental". Anthropic stays experimental.
  **Outcome (§7.5):** no re-qualify ran, and the release went out saying "tested live". The docs now say "qualified
  live on v0.5.2 (2026-10-29); v0.5.3 changed how a cut request is booked and has not been re-qualified yet". The
  catalog's `live` flag in providers.rs (code; `init-root providers` prints "live-tested") ships as is until a
  re-qualify on 0.5.3 or v0.5.4.
- **Signing:** v0.5.3 is the first signed release (lane S). The owner's key ceremony comes before the publish.
- **Version:** a patch (fixes, statistics and signing as an additive asset; no format change).
