    - HTTP error classification, including the overflow heuristic.
    - The §3.10 flatten fallback for foreign turns.
    - The adapter's bytes are **identical to WP12's `context::render`** for the same conversation and to WP12's golden head request.
  - `anthropic.rs` and `openai.rs`: both adapters, each with build, decoder and classify.
    - Anthropic: B1/B2/B3/A markers, steer merge, thinking-binding header and `block_binding`, plus the binding-off and strip-thinking fallbacks.

  - `handoff.rs`: the §3.10 filter (per-block thinking rule, opaque blocks per api, image replacement, call-id sanitizing with collision suffixes) and `from_msgs` (context `Msg` → normalized `Message`).

  - `client.rs`: `Client` implements `ModelClient`. It sends `req.body` unchanged with the API's path and headers. It also has `send_body` and `send_prompt`.

## Deviations
1. **Types live in `src/model.rs`**, shared across lanes, not in `provider/mod.rs`. `Api` is re-exported from `context::model`. `Abort` takes a `kill_group: fn(i32)` hook, so the type does not depend on `tools`.
2. **The byte-based `model::Request`** was agreed with B1. `Context::next_request` already renders the body, so `Client` sends it unchanged. provider.md §3.3's `Request` is named `provider::Prompt` and is the input to `Provider::build`. The trait gains `wire(body)`, `classify(..)` and `fallback(..)`, and `decoder()` takes no request.
3. **The fallbacks rewrite the body JSON** (Anthropic binding-off and strip-thinking, DeepSeek flatten), so they also work on context-rendered bytes.
4. **DeepSeek flatten adds `"reasoning_content": ""`** to the flattened assistant turns and to any assistant message that lacks the field. Reason: DeepSeek documents that the field is required on *every* assistant message in tool mode, and `--strict` enforces that, so the doc's bare flatten would get another 400. V-DS-3 decides.
5. **The DeepSeek decoder emits `ToolCallReady`** at the `finish_reason` chunk. A chunk carrying an `error` object becomes `Stream{Other}`. `Origin.model` and `Thinking.model` take the request's model id, not the chunk's.
6. **Anthropic:**
   - Partial (aborted) thinking without a signature keeps its text with `native: None`, so it is never replayed.
   - A 429 without `retry-after` is `Billing`, as the spec says.
   - 504 maps to `Server`.
   - **OpenAI:** a `response.completed` that saw a refusal maps to `Refusal{category: None}`.
7. **Socket timeouts are set best-effort.** macOS returns EINVAL from `setsockopt` once the peer has closed, and the next read or write then reports the real condition.
8. **`INIT_TEST_CONNECT_TIMEOUT_MS` is accepted but not applied:** `connect` on AF_UNIX does not block.
9. **Fixture location:** fixtures live in `seed/src/provider/testdata/`, not testing.md's `seed/tests/fixtures/`. That keeps them inside WP10's paths, and a bin crate's `tests/` cannot reach internal modules anyway.
   - `deepseek/api-reference-example.sse` was reconstructed offline from the API reference's documented example (there was no network). It is **not verified byte for byte** (item 4(i)).
10. **No native usage object:** `AssistantMessage` has no field for the provider's raw usage, so the loop logs `usage.native = None`.
11. **`Usage::to_log` takes `self`** (Copy; a clippy fix).
