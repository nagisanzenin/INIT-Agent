## Deviations
1. `model::Request` is byte-based: log-context already renders the wire body, and the provider sends it unchanged. Agreed with WP10.
2. `ContextHooks` differs from loop.md §4.2:
   - `boundary_append` returns WP12's `BoundaryOut`;
   - `on_response` takes `Timing`;
   - `has_input` and `session_id` are added.

   `BoundaryInput.results` is `(name, ToolResult)`, `reload` is one `ReloadIn` per tier, and `errors` is added.
3. The loop never calls `process::exit`. `serve()` returns the exit code (0, 75, 1, or `FAULT_EXIT` 134 in tests), and the caller flushes `out` and exits.
4. `CaptureSpec::Merged` has an extra `name` field, the spill file name.
5. `Prepared` carries `idx`, `call_id` and `name`, and `Tools::run` returns `Ran{result, summary}`.
6. `ToolCx` has `images`, `model_id` and `paths: PathCx` instead of `&ModelInfo`, `cwd` and `home`.
7. `ExtHostApi` is a trait with `Snapshot = Arc<dyn Any + Send + Sync>`, so the loop and tools never see Wasmtime types.
8. **`read` similar names.** A name also qualifies at edit distance ≤ 2. The doc's own example (`src/lop.rs` → `src/loop.rs`) does not share three leading characters.
9. **`read` and the generic cap.** Read results skip the generic 51,200-byte cap, because their trailer can pass it by a few bytes; read is bounded by its own limits (§3.1).
10. **Timeout trailer.** It says `(TERM)` when TERM was enough, and `(TERM, then KILL after 2s)` otherwise.
11. **CRLF in bash output.** It becomes LF in the model text; the spill file stays raw.
12. **Pause.** It emits `state{busy:false}`, and a resume in the middle of a run emits `state{busy:true}`. An interrupt that arrives while paused is cleared on resume.
13. **Queued follow-ups at abort, failed and pause boundaries.** They are appended as owner messages ("queued items", §3.4). A steer left over at idle starts a run.
14. **Reload.**
    - T0 runs only when boot supplies a `HeadSource`.
    - `reload_done` waits for the T1 report, which is polled every 100 ms while idle.
    - A T1 report taken before an `ext` batch (60 s wait) is logged at the next boundary.
15. **Error `where` values.** `provider` for provider-side codes, `loop` for `length_guard`, `context` for render errors.
16. **Panic results.** The message has no source location; the location is in the panic hook's stderr line.
17. **Spill total.** The session spill total is a process-global counter; boot calls `tools::bash::init_spill_total`.
