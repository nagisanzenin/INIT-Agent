## Deviations
1. The line has a leading `- ` like every other boot-block line; the rest is the ADR's text.
2. The Root's views are folded in `rootview.rs` (the body's Root-view reader) rather than `awareness.rs`, which stays
   a pure renderer; `tests/boot.rs` gained the live head test. Both are seed files outside the WP row's list.
3. `L0→L1 4d` is read as the days still needed at this level; when days are met the line shows the next unmet
   criterion instead. The autonomy line keeps the full list.
4. The line is rendered once per boot (P2). Between boots the skill points at `root/extend.json` and `root/caps.json`.
5. Archive move commit type: `retire` refuses new files (deletion-shaped), so the skill says `refactor(archive)` for
   a move and `retire` with `Retires:` for a delete.
