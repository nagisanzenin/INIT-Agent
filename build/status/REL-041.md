| Bin-dir guard | the first preflight check, before anything is written: `INIT_BIN_DIR` must be absolute and must not be `/sbin`, `/usr/sbin`, `/bin`, `/usr/bin` (`[ "$BIN_DIR" -ef "$d" ]`, device and inode, so symlinks, `..`, `//`, trailing `/` and case variants match; plus a string compare for a missing path). tests/install/test_install_guards.py (5 tests) and a ci/local.sh step |
| Uninstall | moves `init-agent`, `init-tui` and INIT's `init` (old launcher or shim, by marker) to the Trash; a foreign `init` stays |

| Harnesses | release-e2e.sh: a foreign `init` survives install and uninstall byte for byte; bundle-e2e.sh: INIT's old launcher is planted before get.sh, removed on Linux, the shim on macOS (`init --which` = `init-agent --which`, the notice on stderr); gbal_proof.sh drives `init-agent` |
| Docs | README and 14 docs files (`init` → `init-agent` where it is the launcher; notes in tui.md §3.1, guide.md "Install", platforms.md §3.4.0, release.md §5).
